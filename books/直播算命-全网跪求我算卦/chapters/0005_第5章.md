## CHAPTER_TITLE

第5章 观棋人

## CHAPTER_CONTENT

林默看着周远，想了大概五秒钟。

这五秒钟里他做了一个快速的决策树分析——说实话，说假话，说一半真话。

说实话："我有一个绑定在意识里的玄学系统，每天能窥视三次天机。"结果：周远叫120。

说假话："我瞎蒙的。"结果：周远不信，而且后续合作的基础就没了。

说一半真话。

"我师父是青城山清虚观的道士，"林默说，"他去世之前教了我一些东西。"

这句话是真的。

周远的笔停了一下。"青城山？道士？"

"嗯。我从小在山上长大，七岁上山，十五岁下山读书。我师父法号清虚，是清虚观的主持。三年前去世了。"

"所以你是……道士？"

"我没有正式的度牒，"林默说，"算是俗家弟子。我师父教了我一些观相、推演的方法，但我一直没当回事，觉得是封建迷信。直到最近——"

他斟酌了一下用词。

"直到最近，我发现有些东西可能不完全是迷信。"

周远把这些记在本子上，字迹很快，但很工整。他写完抬头："所以你的意思是，你是通过某种……传统的玄学方法，算出了李婷婷的位置和龙啸天的车祸？"

"差不多。"

"能具体说说是什么方法吗？比如算卦？看相？"

"你让我怎么具体？"林默反问，"我跟你说'我起了一卦，天风姤变火风鼎，六爻动，世应相冲'，你听得懂吗？"

周远诚实地摇了摇头。

"所以就别问具体方法了，"林默说，"你只需要知道两件事。第一，我说的信息到目前为止都是准确的。第二，我没有任何违法手段获取这些信息——没有黑客入侵，没有非法监听，没有内部人员泄露。你可以查。"

周远又记了几笔，然后放下笔，关掉了录音。

"下面说的不录了。"他靠回椅背，看着林默，"我个人问你一个问题。"

"问。"

"你信这个东西吗？你自己信吗？"

林默没有立刻回答。

他想了想，说："一个星期前我不信。现在——我不确定我信不信，但我确定它是有效的。对我来说，有效比信不信更重要。"

周远点了点头，像是能理解这个回答。他犹豫了一下，说了一句看似不相关的话："我们王队——王建国，你知道吧——他奶奶是青城山的信徒。每年都要上山烧香，八十多了还爬得动。"

林默挑了一下眉毛。"所以？"

"所以他对这类事情的态度比一般人……宽容一些。昨晚他看完你的直播录屏，没说你是骗子，也没说你是神仙。他就说了一句话：'这个人，得见一见。'"

"见一见是什么意思？请我喝茶？"

"不是那种喝茶，"周远笑了一下，"就是字面意思，见一见，聊一聊。他说如果你的能力是真的，那对我们来说——"

他没说完，因为门外传来了敲门声。

不是拍铁门的那种粗暴的敲法，是很规矩的三下，节奏均匀，力度适中，像是敲门这个动作本身也经过了训练。

林默和周远对视了一眼。

"你约了别人？"周远问。

"没有。"

林默走过去开门。

门外站着一个人。

男性，大约三十岁出头，中等身材，穿着一件灰色的亚麻衬衫，下面是深色的休闲裤和一双布鞋。头发不长不短，干净利落，没有任何多余的装饰。整个人给人的感觉就是两个字——干净。不是那种刻意的干净，是从里到外的、习惯性的干净。

他的眼睛很亮，但不是那种咄咄逼人的亮，更像是一潭很深的水，表面平静，底下有东西在动。

"林默先生？"他微微欠身，语气礼貌但不卑不亢，"冒昧打扰。我姓陆，陆子期。"

林默没有让开门口。"你找我什么事？"

陆子期微微一笑："我受人之托，来送一样东西。"

他从衬衫口袋里取出一张名片，双手递过来。

林默接过来看了一眼。

名片是竹纸做的，质感很好，上面只有简简单单几行字：

中华玄学文化研究协会
理事 陆子期
电话：138××××××××

没有地址，没有邮箱，没有二维码。简洁到了近乎傲慢的程度。

"玄学协会？"林默说。

"对。"陆子期的目光越过林默的肩膀，看到了屋里的周远，微微点了点头，"这位是？"

"警察。"林默说，没有详细介绍的意思。

陆子期没有表现出任何意外或不安。他只是点了点头，说："那我长话短说，不耽误林先生的时间。"

他从随身的布包里取出一个信封，同样是竹纸的，封口处用火漆封着，火漆上压了一个篆体的"玄"字。

"这是我们会长张玄清先生的亲笔信。张会长看了林先生昨晚的直播，有一些想法，想与林先生当面交流。信里有具体的时间和地点。"

林默没有接信封。

他看着陆子期，问了一个问题："你的网名是不是叫'清风明月观棋人'？"

陆子期的表情没有变化，但他的眼睛里有什么东西闪了一下——很快，快到普通人不会注意到。但林默注意到了。

"林先生很敏锐。"陆子期说，算是默认了。

"你昨晚在我直播间里。"

"是的。"

"你在微博上发了一条长评，分析我的眼神、动作和行为逻辑。"

"是的。"

"你分析得很专业。"林默说，"太专业了。一个普通观众不会注意到我按太阳穴的动作，更不会把它和鼻血联系起来，得出'身体代价'的推测。除非他本身就懂这些。"

陆子期没有否认。他只是微微偏了一下头，像是在重新评估面前这个穿着皱巴巴T恤、顶着黑眼圈的年轻人。

"林先生是青城山清虚观的传人，"他说，语气里多了一丝认真，"清虚道长在世时，在玄门中颇有声望。他的传人，自然不会是普通人。"

这句话里的信息量不小。

林默抓住了关键词："颇有声望？我师父？"

他是真的意外。在他的印象里，老道士就是一个邋遢的、爱喝酒的、总是念叨"别拿这玩意儿炒股"的老头。青城山清虚观是一个很小的道观，小到连旅游地图上都没有标注，每年的香火钱还不够修屋顶的。

"清虚道长精通青囊术，在玄门内部是公认的。"陆子期说，"只是他老人家性情淡泊，不喜交际，所以外界知道的人不多。但玄学协会的档案里，有他的名字。"

林默沉默了几秒。

他突然意识到，自己对师父的了解可能远比他以为的要少。

这时候，系统在他视野边缘弹出了一行字：

【提示：陆子期，玄学协会理事，修为"灵觉"初期。对宿主无敌意，但携带探测类法器（左手腕处），正在被动感知宿主气息。建议宿主注意信息暴露程度。】

林默的目光不动声色地扫了一眼陆子期的左手腕。袖口下面露出一截手串，看起来像是普通的檀木珠子，但其中有一颗的颜色比其他的深一些，表面有一层不易察觉的光泽。

探测类法器。

这人来送信是真的，但顺便摸底也是真的。

林默做了一个决定。他接过信封，但没有当场拆开。

"信我收了，"他说，"但我有几个问题。"

"请说。"

"第一，你们会长为什么要见我？是因为昨晚的直播，还是因为青城山清虚观？"

陆子期想了想，给了一个诚实的回答："都有。昨晚的直播让张会长注意到了林先生，但青城山清虚观的传承，是他决定亲自写信的原因。"

"第二，你们想从我这里得到什么？"

"交流。"陆子期说，"仅此而已。玄门传承各有不同，青囊术是其中非常独特的一脉。张会长研究玄学五十年，对青囊术一直很感兴趣，但清虚道长在世时从不与外人讨论。现在——"

他顿了一下，措辞很谨慎。

"现在清虚道长已经仙逝，他的传人出现在公众视野中，张会长认为这是一个合适的时机。"

林默听出了这句话里没说出来的部分：清虚道长活着的时候，他们不敢来；清虚道长死了，他们觉得可以来了。

这让他对这个"张玄清"的第一印象打了个折扣。

但他没有表现出来。

"第三个问题，"林默说，"你手腕上那串珠子，是用来探我底的吧？"

陆子期的表情终于有了一丝变化。

不是惊慌，是意外。真正的意外。他下意识地看了一眼自己的左手腕，然后抬头看着林默，眼神里的"评估"变成了"重新评估"。

"林先生果然是清虚道长的传人。"他说，语气里多了一层东西——不是恭维，更接近于确认。

他没有否认，也没有道歉。他只是把左手腕上的手串往袖口里推了推，算是一个"收起来了"的姿态。

"这是协会的例行程序，"他说，"初次接触未知修行者时，需要确认对方的基本情况。没有恶意。"

"我知道没有恶意，"林默说，"但下次先打个招呼。"

陆子期点头："是我失礼了。"

门口的对话进行到这里，周远一直坐在屋里没动，但他的眼神一直在林默和陆子期之间来回切换。他听不懂什么"青囊术""灵觉""法器"，但他的职业直觉告诉他，这个穿亚麻衬衫的男人不简单。

林默转头看了周远一眼，周远会意，站起来走到门口。

"我笔录做完了，"周远说，对陆子期点了点头，"你们聊，我先走。"

他走到林默身边的时候，压低声音说了一句："小心点。"

然后他走了。

陆子期目送周远离开，转回头看着林默："林先生，信里的内容您可以慢慢看。张会长说了，不急，什么时候方便什么时候来。"

"行。"

"那我就不打扰了。"陆子期再次微微欠身，转身要走。

走了两步，他又停下来，回头说了一句："对了，林先生——张会长让我转告一句话。"

"什么话？"

"他说：'青城山的星星，比城里的亮。'"

林默愣了一下。

这句话本身没什么特别的，但说这句话的方式——像是一个暗号，又像是一个试探。

陆子期没有解释，转身走进了城中村的巷子里，很快就消失在拐角处。

林默关上门，回到屋里。

他在椅子上坐下，把那个火漆封口的信封放在桌上，看了一会儿。

然后他先没拆信，而是拿起手机。

手机上又多了一堆通知，但他直接忽略，翻到一个陌生号码发来的短信。这个号码昨晚打了他四次，他都没接。

短信内容是：

"林默先生您好，我是龙振华的秘书王芳。龙总委托我转达对您的感谢，并已向您的直播账户转入感谢金，请查收。龙总说，如果您方便的话，希望能当面致谢。这是龙总的私人号码：139××××××××。"

林默打开抖鱼直播的后台，看到了一条新的打赏记录：

用户"龙啸天不啸了"打赏"青城山林默"——帝王套餐 × 1（价值100,000鱼丸，约合人民币10,000元）。

附带留言："救命之恩，改日当面谢。这点钱不成敬意，后面还有。——龙啸天"

林默盯着这条记录看了几秒。

一万块。加上昨晚的两万四。三万四了。

他银行卡里本来只有三千二。

他深吸了一口气，把手机放下，拿起了那个信封。

火漆很硬，他用指甲抠了半天没抠开，最后用了一把水果刀。信封里是一张折叠的宣纸，上面是毛笔字，繁体，竖排，字迹苍劲有力，一看就是练了几十年的人写的。

信不长：

"林默小友台鉴：

老朽张玄清，忝为中华玄学文化研究协会会长，久仰清虚道兄大名。惊闻道兄仙逝，未能亲往吊唁，至今引以为憾。

近日偶见小友直播，观其手法，颇有青囊遗风。老朽不才，研习玄学五十载，于青囊一脉始终未能窥其堂奥。今小友既已入世，老朽斗胆相邀，望能一晤。

非为考校，亦非为难。只是同道中人，叙一叙旧，论一论道。

时间地点，悉听小友安排。陆子期可代为联络。

顺颂道安。

张玄清 手书"

林默把信看了两遍。

这封信写得很客气，客气到了小心翼翼的程度。一个七十岁的玄学协会会长，给一个二十五岁的前程序员写信，用的是"小友""台鉴""斗胆"这种措辞。

要么是真的尊重清虚道长的传承，要么是在试探他的深浅。

或者两者都有。

他把信放回信封里，靠回椅背，闭上眼睛。

太阳穴的钝痛又冒出来了，不重，但存在感很强，像一个不断闪烁的提示灯。

系统在视野边缘弹出了一行新的提示：

【检测到玄门组织接触事件。建议宿主谨慎评估合作可能性。】

【补充信息：张玄清，年龄72岁，修为"通幽"后期，中华玄学文化研究协会创始人之一。对青囊术有长期研究兴趣，但从未获得清虚道长认可。】

【注意：以上信息来源为天机数据库被动索引，非主动窥视，不消耗每日额度。】

林默睁开眼睛，盯着最后那行字。

"被动索引"。

昨晚的"被动触发"，今天的"被动索引"。系统似乎有越来越多的"被动"功能在自行启动，而这些功能他从来没有主动要求过。

"你什么时候多了这个功能？"他问。

系统回应：

【天机数据库被动索引功能于宿主绑定系统时即已存在，但仅在宿主接触玄门相关人员/组织时自动激活。此为安全防护机制，确保宿主在玄门交际中不处于信息劣势。】

听起来合理。但林默总觉得哪里不对。

一个"工具"不会主动替使用者考虑安全问题。除非它不只是一个工具。

他把这个念头记在心里，没有追问。

富贵从阳台上跳下来，颠颠地跑到他脚边，用脑袋蹭他的小腿。林默低头看它，发现它的眼睛正盯着桌上的信封，瞳孔微微放大，像是对那张竹纸很感兴趣。

"你又不识字。"林默说。

富贵"喵"了一声，跳上桌子，在信封上踩了两脚，然后一屁股坐在了上面。

林默把它抱下来。

他拿起手机，找到陆子期的名片，把号码存了进去。然后他编辑了一条短信，想了想，又删掉了。

不急。张玄清说了"悉听小友安排"，那就让他等一等。

他现在需要做的事情有三件：第一，搞清楚师父在玄门中到底是什么地位，为什么一个"通幽后期"的老头要对一个小道观的主持这么客气；第二，搞清楚系统的"被动"功能到底有多少，边界在哪里；第三，决定今晚要不要继续直播。

前两件事需要时间，第三件事需要现在做决定。

他打开抖鱼直播的后台，看了一眼数据。

粉丝数从昨晚的118,812涨到了现在的——

他眨了一下眼睛。

203,547。

一个上午涨了将近九万。

而他什么都没做。

后台还有一条平台运营的私信："林默老师您好，我是抖鱼直播的运营经理小赵。鉴于您近期的高关注度，平台希望与您探讨进一步的合作可能。方便的话请回复您的联系方式，我们可以安排一次线上会议。"

林默没有回复。

他关掉手机，站起来，走到阳台上。

城中村的中午很吵。楼下有人在吵架，隔壁在炒菜，远处的工地在打桩。阳光很烈，照在对面楼房的铁皮屋顶上，反射出刺眼的白光。

他眯着眼睛看了一会儿，然后低头看着手里那张竹纸名片。

中华玄学文化研究协会。

他以前从来不知道这个世界上还有这种组织。在他的认知里，"玄学"就是老道士在山上教他的那些东西——背不完的经文、画不好的符、看不懂的星图。他一直以为那些东西会随着老道士一起消失在青城山的云雾里。

但现在它们追到了城中村。

追到了他的直播间。

追到了他的门口。

他把名片收进口袋，回到屋里，坐到电脑前。

他打开一个新的文本文档，像写代码注释一样，列了一个清单：

```
// TODO:
// 1. 回复陆子期，约见张玄清（地点选公共场所，别去他的地盘）
// 2. 翻《青囊天机录》，找师父关于玄学协会的记录（如果有的话）
// 3. 今晚直播——但换个方式，不能再搞预言车祸这种高风险操作
// 4. 功德值还差20到50，研究一下怎么高效攒功德
// 5. 龙振华那边，先不回，观察
//
// BUG: 系统的"被动"功能越来越多，需要持续监控
// WARNING: 太阳穴还在疼，身体是硬件，别把硬件跑崩了
```

他保存了文档，关掉电脑。

然后他从书架最底层——其实就是一个纸箱子——翻出了一本泛黄的线装书。

《青囊天机录》。

老道士的手稿。封面上的字已经褪色了大半，但还能辨认。书页边缘有茶渍和酒渍，有些地方还有橘猫的爪印——富贵刚来的时候踩的。

他翻到目录页，手指沿着条目往下滑。

"卷一：天机总论"
"卷二：观相篇"
"卷三：推演篇"
"卷四：符箓篇"
"卷五：禁忌篇"
"附录：杂记"

他翻到附录。

老道士的"杂记"是整本书里最有意思的部分，因为它不像前面几卷那样正经，更像是一个老人的随笔日记，想到什么写什么，字迹也比正文潦草得多。

他快速翻了几页，在第三页找到了一段：

"甲子年秋，玄协张某来访，欲观青囊术。拒之。此人修为尚可，心术不正不邪，只是太执着于'术'而忽略了'道'。青囊之妙，不在术，在心。心不到，术再精也是皮毛。"

张某。张玄清。

林默继续往下翻。

隔了几页，又有一段：

"丙寅年春，张某又来。带了两个弟子，说是'交流'。交流了三天，问了一百多个问题，我答了三个。他走的时候脸色不太好看。无所谓，我又不靠他吃饭。"

林默嘴角微微抽了一下。这很老道士。

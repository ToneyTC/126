# 第17章 三楼的空调

师父教的土办法很简单：数自己的脚步。

一步，两步，三步。鞋底碾过碎石子的声音填满耳朵，把后脑勺那股被盯着的感觉往下压。林默没回头，拐进了路边一家还亮着灯的打印店。

"打印东西。"他对柜台后面玩手机的小伙子说。

小伙子头也没抬："U盘插左边那台。"

林默没有U盘，也不需要打印。他站在柜台前，借着玻璃门的反光往外看。

街上人不多，路灯刚亮，把行道树的影子拉得很长。一个推婴儿车的女人经过，一个外卖骑手停在路边看手机，再远处有两个中学生模样的男孩在踢易拉罐。

没有灰外套。没有任何人在门口停留或放慢脚步。

他又等了三十秒。玻璃门外的街道安静得像一幅画，只有外卖骑手重新跨上电动车，嗡地开走了。

"打不打？"小伙子终于抬头看他。

"不好意思，U盘忘带了。"

林默推门出去，空气里有烧烤摊的油烟味，混着初夏傍晚特有的闷热。他往左拐，朝出租屋的方向走，这次后脑勺的感觉消失了。

可能是错觉。也可能那个人只跟了一段就放弃了。

他没有放松，但脚步恢复了正常速度。

走到巷口的时候，手机震了一下。王建国的消息：

"照片收到了。130号那个交接你拍得不错，放大能看清帆布袋上的商标。我让人查了，是环城东路批发市场卖的那种，十五块一个，没什么追踪价值。但袋子里露出来的那根铜管有意思。"

林默没回消息，先上了楼。

钥匙插进锁孔的时候，他下意识看了一眼对面楼三楼的窗户。窗帘拉着，没有灯光，和过去二十天一样死气沉沉。但他现在知道了，那只是个前哨。真正的东西在环城东路132号三单元。

门开了，富贵从鞋柜上跳下来，尾巴竖得笔直，围着他的脚踝转了两圈，然后停下来，鼻子朝他的裤腿使劲嗅。

"闻到什么了？"林默蹲下来。

富贵打了个喷嚏，退后两步，耳朵往后压了压，又凑上来闻。反复了三次，最后跳回鞋柜上，蹲在那里盯着他，瞳孔缩成两条细缝。

猫对灵气敏感。上次他用明目符之后，富贵也是这个反应，但没这么强烈。

林默低头看自己的裤腿。深色运动裤，看不出什么异常。但他在132号三单元楼下站了至少五分钟，那栋楼三楼窗户外泄的灵气，可能沾了一些在衣服上。

他把外套和裤子换了，扔进洗衣机，开了速洗。富贵这才从鞋柜上下来，恢复了平时的样子，跳上桌子趴着，尾巴尖慢慢摆动。

铜钱剑还在床头，和他出门前一模一样。林默拿起来握了握，掌心传来熟悉的凉意，心里踏实了一点。

他坐到桌前，给王建国回了消息："铜管什么意思？"

电话直接打过来了。

"你现在安全吗？"王建国开口第一句话不是铜管。

"回来了，门锁好了。"

"我说的安全是，你确定没被跟？"

林默想了想打印店玻璃门里的画面："不确定。回来的路上有一段感觉不对，但没看到具体的人。进了一家打印店等了一会儿，出来之后就没了。"

电话那头沉默了几秒。

"林默，我上次怎么跟你说的？"

"你说别出门。"

"那你干了什么？"

"出门了。"

王建国的呼吸声变重了。林默能想象他的表情，眉头拧在一起，嘴角往下拉，像个被学生气到的班主任。但王建国没发火，他的声音反而压得更低了。

"你拍的照片确实有用。130号和132号之间有交接，这个我们之前不知道。但你想过没有，如果那个灰外套发现你跟着他了呢？"

"他没发现。"

"你怎么确定？"

林默没说话。他确定不了。他只是保持了距离，利用了路上的行人做掩护，但他毕竟不是专业的。

"你确定不了。"王建国替他说了，"你一个人，没带任何防身的东西，跟着一个我们还没搞清楚底细的人，走了将近两公里。如果他在某个巷子里等你呢？"

"我知道。"

"你知道，但你还是去了。"王建国的语气里没有愤怒，是一种更让人不舒服的东西，疲惫。"林默，我不是你爸，管不了你。但我得把话说清楚，你手里的东西，那些照片，那些定位数据，那些你用你的方法搞到的信息，对我来说都有用。但如果你出了事，这些东西一文不值。"

林默靠在椅背上，盯着天花板上的水渍。王建国说得对。他今天确实冒了不该冒的险。明目符能看到灵气，但挡不了刀子。

"好，我听你的。"他说。

"真的？"

"至少今晚是真的。"

王建国哼了一声，算是接受了这个打了折扣的承诺。

"说铜管的事。"他的语气切换回了工作模式，"你拍的第三张照片，帆布袋口子敞开的那张，放大之后能看到一根铜管，大概三十公分长，管壁上有刻痕。我让人比对了一下，不是普通的水暖管件。"

"什么样的刻痕？"

"照片不够清楚，但看着像是某种纹路，重复的，有规律的。你那个，你们那行的人，能看出来是什么吗？"

林默回忆了一下明目符视角下帆布袋里的画面。当时他的注意力集中在整体的灵气残留上，没有细看每一件物品。但铜管这个信息和他在古籍《青囊符录·残卷》里看到的某段描述对上了。

"可能是引气管。"他说，"用来把灵气从一个地方导到另一个地方。管壁上的刻痕是导引纹，控制灵气流动的方向和速度。"

"你确定？"

"不确定。照片太糊了，我需要看到实物，或者更清楚的图。"

"实物你别想了。"王建国的语气很干脆，"更清楚的图我想办法。"

"怎么想办法？"

"132号三单元，户主郑海平，我下午查了。这人有意思。身份证地址是甘肃天水的，但户籍系统里的照片和你房东吴姐描述的'姓郑的老头'对不上。吴姐说那人六十多岁，瘦，头发白了大半。郑海平的户籍照片是个四十出头的中年人，圆脸，头发浓密。"

林默的手指在桌面上停了一下。

"套用身份？"

"有这个可能。也可能是照片太旧，人变化大。但我倾向于前者。一个甘肃天水的人，跑到江城租了两套房子，一套在你对面楼，一套在环城东路132号，两套房子之间有人定期运送带灵气的材料。这不是正常的租房行为。"

"你能查到他的租房合同吗？"

"132号的房东我已经联系上了，姓马，在外地做生意，房子委托给中介打理。中介那边的合同我明天去调。但有个问题。"

"什么问题？"

"132号的租约是去年九月签的，签了一年，到今年九月到期。你对面楼那套，吴姐说是前年就租了，也是一年一签。两套房子，租了快两年，每个月光房租就是四五千。这个郑海平，或者说用郑海平身份的人，花了将近十万块租房子，图什么？"

林默没有回答。他知道图什么，但那个答案涉及灵气、阵盘、引气管这些王建国目前还没有完全接受的东西。

"周志远那边呢？"他换了个话题，"五点的传唤，有结果了吗？"

王建国的语气变了，带上了一种林默不太熟悉的东西。如果非要形容，像是一个人咬了一口苹果，发现里面有半条虫子。

"有结果。"他说，"周志远没来。"

"什么意思？"

"传唤通知书下午两点送达的，他签了字，说五点准时到。结果到了五点，人没来。打电话，关机。去翠园小区找，邻居说他下午三点多就出门了，拎了个行李箱。"

林默坐直了。

"跑了？"

"不好说。传唤不是强制措施，他有权利不来，顶多算不配合。但这个时间点跑，配合他之前撒的那些谎，味道就不对了。"

"你们能找到他吗？"

"手机关机，没法定位。高铁和飞机的实名购票系统我让人查了，截至目前没有周志远的购票记录。要么他用了别人的身份，要么他没走远，就在江城躲着。"

林默的脑子转得很快。周志远跑了，这件事本身就是一个信号。一个清白的人不会在传唤前三小时拎着行李箱消失。但周志远跑的时机也很微妙，下午两点签收传唤通知，三点就走了，中间只有一个小时。

一个小时够干什么？打一个电话，收拾一个行李箱，叫一辆车。

"他可能联系了什么人。"林默说。

"我也这么想。他签收传唤通知之后，一定给某个人打了电话或者发了消息，那个人告诉他跑。问题是他手机关机了，通话记录要走流程调取，最快明天下午。"

"如果他联系的是132号的人呢？"

电话那头安静了很长时间。

"你是说，周志远和132号之间有直接联系？"

"他当天在环城东路120到140号之间待了两个多小时。132号就在这个范围内。他去那里干什么？见谁？如果他见的就是132号的人，那他签收传唤通知之后第一个联系的，很可能也是那个人。"

王建国没有立刻回应。林默听到他那边有翻纸的声音，大概是在看之前整理的时间线。

"逻辑上说得通。"王建国终于开口，"但我需要证据。通话记录是一条路，132号的监控是另一条。环城东路那一片老小区多，公共监控覆盖率不高，但132号门口的路灯杆上有一个球机，我下午路过的时候注意到了。明天去调。"

"你下午去了132号？"

"路过。"王建国的语气很平，"我也不是只会坐在办公室里的。"

林默没再说什么。王建国比他想象的更主动。一个律师，拿着并不丰厚的代理费，做着远超职责范围的调查工作。这里面有职业习惯的成分，但更多的，林默觉得，是周淑芬的案子本身触到了王建国的某根神经。

"还有一件事。"王建国说，"你的直播，申诉通过了。"

林默愣了一下。这个消息来得太突然，和前面那些沉重的信息放在一起，像是一盘黑白棋子里混进了一颗彩色弹珠。

"什么时候的事？"

"平台下午四点发的通知，发到你注册邮箱里了。我帮你写的申诉材料起了作用，他们认定举报证据不足，恢复了你的直播权限。但有个附加条件，三十天内如果再被举报且查实，直接永封。"

林默打开邮箱，确实有一封来自平台的邮件。措辞很官方，大意是经核实，您的账号不存在违规行为，现已恢复正常使用，请遵守平台规范云云。

他盯着那封邮件看了十几秒。

直播是他目前唯一的收入来源。封禁这几天，他靠之前攒的一点打赏提现撑着，房租、饭钱、给老陈的路费，加起来已经花了不少。如果再封一个月，他连房租都交不起。

但现在解封了，他反而没有立刻高兴起来。

因为举报他的人还在。那个人知道他的直播账号，知道他在做什么，甚至可能知道他住在哪里。解封只是意味着他可以继续赚钱，但也意味着他重新暴露在那个人的视线里。

"你在想什么？"王建国问。

"在想要不要马上开播。"

"我的建议是，开。"王建国说，"第一，你需要钱。第二，你停播这几天，对方可能以为你被吓住了。你重新开播，等于告诉他，举报这条路走不通。第三，也是最重要的，你直播的时候是有观众的，几千人同时在线，这本身就是一种保护。一个有几千人关注的主播，比一个默默无闻的租客更难被悄无声息地处理掉。"

这个逻辑林默之前没想过。他一直把直播当成赚钱的工具，没想过它还有这层功能。

"但三十天内不能再被举报查实。"他说。

"所以你直播的时候注意一点，别说太具体的地址，别提案子的细节。你之前那种风格，帮人看事儿，解答问题，挺好的，继续就行。"

"行。"

"还有，"王建国顿了一下，"老陈那边有消息了。"

林默的注意力立刻集中起来。老陈去兰州已经两天了，昨天成功接触了陈永强，今天应该有进一步的动作。

"他下午给我发了一段语音，将近三分钟。我给你转述一下要点。"王建国清了清嗓子，"老陈今天又去了永强建材，这次没买东西，就在店里坐着喝茶聊天。陈永强这个人，话不多，但不排斥和人聊。老陈用的切入点很聪明，他说自己是做装修的，在兰州接了个活儿，需要长期供货，问陈永强能不能给个批发价。"

"陈永强怎么说？"

"答应了。还主动带老陈去后面仓库看了货。老陈说仓库不大，就一间铁皮房，里面堆的都是瓷砖、地板砖、五金件，很正常的建材生意。但他注意到一个细节。"

"什么细节？"

"仓库角落里有一张折叠床，床上有被子和枕头，旁边放着一个电热水壶和几桶方便面。老陈问他是不是住在店里，陈永强说最近在装修自己的房子，暂时住店里凑合。但老陈觉得不对，那张折叠床的被子很旧，枕头都压扁了，不像是'最近'才住的。"

林默把这个信息记下了。陈永强长期住在店里，可能是经济原因，也可能是在躲什么。一个从江城跑到兰州开建材店的人，住在自己的仓库里，这个画面本身就不正常。

"老陈还说了一件事。"王建国的语气变得谨慎，"他在店里聊天的时候，陈永强接了一个电话。电话很短，不到一分钟，陈永强全程只说了三个字：'知道了。'挂了电话之后，他的态度明显变了，开始催老陈走，说下午要去进货。老陈识趣，没多待，但他出门的时候回头看了一眼，陈永强站在柜台后面，两只手撑着台面，低着头，像是在想什么事情。"

"那个电话是谁打的？"

"不知道。老陈没看到来电显示。但时间点很有意思，下午两点四十左右。"

下午两点四十。周志远签收传唤通知是下午两点，三点多就拎着行李箱跑了。中间这段时间，他一定联系了某个人。而陈永强在两点四十接到了一个让他态度骤变的电话。

这两件事之间有没有关联？

林默不敢下结论。时间上的巧合不等于因果关系。陈永强在兰州，周志远在江城，两个人之间隔着一千多公里。但他们都和周淑芬的案子有关，都和那个模糊的幕后网络有关。

"你怎么看？"他问王建国。

"我不怎么看。"王建国的回答很干脆，"我只看证据。时间上的巧合我记下了，但在拿到周志远的通话记录之前，我不会把这两件事硬连在一起。明天下午通话记录应该能出来，到时候一对就知道了。"

这是王建国的做事方式。每一步都要有依据，每一个推论都要有支撑。林默有时候觉得这种方式太慢了，但他也承认，正是这种方式让王建国在法律框架内走得比任何人都稳。

"好，那明天等通话记录。"林默说，"我今晚开播。"

"注意我说的那几点。"

"知道了。"

挂了电话，林默坐在桌前没动。富贵跳上桌子，蹲在他的手机旁边，尾巴搭在屏幕上。

他把手机拿出来，打开直播平台的APP。账号状态已经恢复正常，头像旁边的小红点消失了，取而代之的是一个绿色的"可开播"标识。

他看了一眼时间，晚上七点四十。

之前他固定的开播时间是晚上八点。停播这几天，粉丝群里每天都有人问什么时候回来。他没回复，因为不确定能不能回来。

现在确定了。

他去洗了把脸，换了件干净的黑色T恤，把桌面上的杂物收拾了一下。铜钱剑放在镜头拍不到的地方，手边摆了一杯水。富贵被他放到了床上，但猫不配合，又跳回桌子，蹲在笔记本电脑旁边，正好在镜头边缘。

算了，观众喜欢看猫。

八点整，他点了开播。

直播间的人数跳动着往上涨。十，五十，两百，五百。弹幕刷得很快，大部分是"回来了""终于开播了""被封了好几天啊"之类的。也有人问原因，他没解释，只说平台审核，已经解决了。

"今晚正常看事儿。"他对着镜头说，"排队规矩和以前一样，弹幕发生辰八字，我看到了就说。"

弹幕立刻涌上来一大片八字。林默扫了一眼，挑了一个格式规范的。

"这位，壬申年、丁未月、甲子日、庚午时。"他念出来，停顿了两秒，脑子里系统界面自动弹出了这个八字的排盘。

他已经习惯了这个过程。系统给出的信息像一张透明的图纸，叠在他自己的判断上面。师父教的东西是底子，系统是放大镜。两者重合的部分，他说得很笃定；有出入的部分，他会多想几秒。

"甲木日主，生在未月，土旺木囚。年柱壬申，时柱庚午，金水夹攻。这个八字身弱，好在年干壬水生身，不算太差。"他说得不快，语气平稳，像在和朋友聊天。

"你最近是不是在考虑换工作？"

弹幕回复："对对对！怎么看出来的？"

"今年乙巳年，巳火克申金，你的偏财被冲了。偏财代表额外收入，也代表你对现在这份工作的耐心。被冲了就是待不住了，想动。"

"能动吗？"

"能动，但别急。下半年丙午、丁未两个月火土太旺，你身弱扛不住。等到九月份，辛酉月，金旺生水，水来生木，那个时候动最合适。"

弹幕刷了一排"厉害"。林默喝了口水，继续看下一个。

这种节奏他很熟悉。一个接一个地看，每个人花三到五分钟，中间穿插一些闲聊和互动。观众喜欢他的风格，不故弄玄虚，不搞恐吓营销，说得准就是准，说不准就说"这个我看不太清楚，你再找别人看看"。

直播进行到四十分钟的时候，在线人数稳定在一千二左右。比停播前少了一些，但考虑到断更了好几天，这个数字已经不错了。

他正准备看下一个八字，一条弹幕从屏幕中间飘过去。

"主播，你能看阳宅风水吗？"

这个问题之前也有人问过。林默一般的回答是"可以，但需要看现场照片或者视频，弹幕说不清楚"。但今天这条弹幕后面跟了一句话，让他多看了一眼。

"我家楼上最近总有奇怪的声音，像是有人在地上拖重东西，但楼上住户说没有。物业也上去看了，说一切正常。"

林默的手指在桌面下轻轻敲了两下。

"什么时间段的声音？"他问。

"凌晨两三点。"

"持续多久？"

"十几分钟，然后就停了。每隔两三天一次。"
